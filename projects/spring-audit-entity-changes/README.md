# Spring Boot

## Audit Entity Changes with Hibernate Envers

Spring Data Envers is an extension of Hibernate Envers that provides auditing capabilities to Spring Boot applications. 
It helps track entity changes over time by storing revision history.

## Conclusion

Spring Data Envers provides easy auditing for entities in Spring Boot applications. 
This example demonstrates:

* Setting up Hibernate Envers with Spring Boot.
* Enabling auditing with @Audited.
* Retrieving revision history of an entity.
