# Spring Boot

## Auditing with JPA: @CreatedBy, @LastModifiedBy, @CreatedDate & @LastModifiedDate Example 

Auditing in Spring Boot is useful for automatically capturing metadata like created and modified timestamps and the user responsible for changes.

## Conclusion

* `@EnableJpaAuditing`
* `@CreatedDate / @LastModifiedDate`
* `@CreatedBy / @LastModifiedBy`
* Spring Security for capturing user details
